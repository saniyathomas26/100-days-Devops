
# Day19 - Install adn Configure Web Application
## Task 
In this task, we prepare App Server 1 in the Stratos Datacenter to host two static websites on the same Apache server. The development team has shared backup folders for both sites, and our goal is to configure Apache to serve each website on its own path — all under a custom port (3003).
## Purpose
To establish a scalable web hosting environment within the Stratos Datacenter, allowing the development team to deploy and test static content in an isolated, port-specific configuration.
